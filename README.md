# Android Client - Обучение KOTLIN

## Описание
Android-приложение «Обучение KOTLIN» с элементами геймификации предназначено для изучения языка программирования Kotlin самостоятельно или в среде образовательных учреждений.

## Назначение
- аутентификация и авторизация пользователей (регистрация, вход, восстановление пароля, смена email);
- изучение учебного контента (темы, уровни, теория);
- выполнение практических заданий с написанием кода во встроенном редакторе;
- участие в PvP-турнирах в реальном времени (викторина);
- просмотр рейтинга, истории изменений ELO и глобальной таблицы лидеров;
- редактирование профиля (имя, аватар).

## Технологический стек
- Kotlin, Jetpack Compose (декларативный UI)
- Clean Architecture + MVVM
- Kotlin Coroutines + Flow (асинхронность и потоки данных)
- Retrofit + OkHttp (REST API)
- SignalR (WebSocket для real-time)
- Jetpack DataStore (хранение JWT-токена)
- Jetpack Navigation (навигация)
- JWT-аутентификация (Bearer token через перехватчик OkHttp)

## Структура модулей
- `app/` — точка входа (MainActivity, Application, корневой NavHost)
- `auth/` — модуль аутентификации (AuthViewModel, AuthNavGraph, экраны)
- `learning/` — модуль обучения (LearningViewModel, TaskViewModel, экраны тем, уровней, теории, редактор кода)
- `pvp/` — модуль PvP-турниров (PvpViewModel, PvpManager, экраны лобби, вопросов, результатов)
- `profile/` — модуль профиля (ProfileViewModel, экраны профиля, редактирования, таблица лидеров, история рейтинга)
- `core-data/` — реализации репозиториев, HttpClientFactory, TokenManager, PvpManager (SignalR)
- `core-models/` — интерфейсы репозиториев, DTO, бизнес-сущности, классы состояний (AuthState, LearningState, PvpState)
- `core-security/` — валидаторы (EmailValidator, PasswordValidator, NameValidator)
- `core-ui/` — переиспользуемые Compose-компоненты, тема приложения

## Установка

### Скачивание APK-файла
APK-файл доступен по ссылке:  
[https://github.com/Ulia9595/app-assets/raw/app/app-debug.apk](https://github.com/Ulia9595/app-assets/raw/app/app-debug.apk)

### Установка на устройство Android
1. Скачайте APK-файл по ссылке выше.
2. На устройстве Android перейдите в «Настройки» → «Безопасность» → разрешите установку из неизвестных источников.
3. Откройте скачанный APK-файл и подтвердите установку.
4. Запустите приложение «Обучение KOTLIN».

### Подключение к серверу
При первом запуске приложение подключается к серверу по адресу, указанному в конфигурации. Убедитесь, что компьютер с сервером и устройство Android находятся в одной сети.

## Основные функции

### Регистрация
1. На экране приветствия нажмите «Зарегистрироваться».
2. Введите email и нажмите «Далее».
3. Введите OTP-код из письма.
4. Создайте пароль (минимум 8 символов, заглавная буква, цифра, спецсимвол).
5. Выберите аватар и имя пользователя.
6. Нажмите «Завершить регистрацию».

### Авторизация
1. На экране приветствия нажмите «Войти».
2. Введите email и пароль.
3. Нажмите «Войти».

### Восстановление пароля
1. На экране авторизации нажмите «Забыли пароль?».
2. Введите email и нажмите «Отправить ссылку».
3. Перейдите по ссылке из письма.
4. Введите новый пароль и подтвердите.
5. Нажмите «Установить пароль».

### Обучение
1. В нижней панели выберите раздел «Обучение».
2. Выберите тему из списка.
3. Выберите уровень.
4. Изучите теоретический материал.
5. Выполните практические задания во встроенном редакторе кода.
6. Нажмите «Запустить» для проверки, «Проверить» для сдачи задания.

### PvP-турниры
1. В нижней панели выберите раздел «Турниры».
2. Нажмите «Найти соперника».
3. Дождитесь подбора соперника.
4. Примите приглашение.
5. Отвечайте на вопросы викторины (таймер 45 секунд).
6. Ознакомьтесь с результатами и изменением рейтинга.

### Профиль и рейтинг
1. В нижней панели выберите раздел «Профиль».
2. Просмотрите текущий рейтинг, уровень и прогресс.
3. Нажмите на иконку редактирования для смены имени или аватара.
4. Нажмите на иконку кубка для просмотра глобальной таблицы лидеров.
5. Нажмите на иконку диаграммы для просмотра истории изменения рейтинга.

## Системные требования
- Android 8.0 (API 24) и выше
- Стабильное интернет-соединение (Wi-Fi или мобильные данные)
