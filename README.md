# Сервер аутентификации - ASP.NET Core

## Назначение
Backend-сервер для системы аутентификации пользователей.

## Содержимое проекта
- ASP.NET Core Web API приложение
- Интеграционные тесты
- Примеры конфигурационных файлов
- Статические файлы интерфейса

## Технологический стек
- .NET 8, Entity Framework Core
- JWT аутентификация
- PostgreSQL (в конфигурации примера)
- SMTP для email уведомлений

## Структура
- Контроллеры API
- Сервисы бизнес-логики
- Модели данных
- Миграции БД
- Middleware

**Примечание**: Реальные конфигурационные файлы не включены в репозиторий.
