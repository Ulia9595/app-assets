# Android Client - Game Authentication App

## Описание
Android приложение для аутентификации и управления профилем в игровой системе.

## Структура модулей
- `app/` - Основной модуль приложения
- `auth/` - Модуль аутентификации
- `profile/` - Модуль профиля
- `core-data/` - Работа с сетью и репозитории
- `core-models/` - Модели данных и API
- `core-security/` - Валидация и безопасность
- `core-ui/` - Общие UI компоненты
- `core-notifications/` - Уведомления
- `integration-tests/` - Интеграционные тесты

## Технологии
- Kotlin, Jetpack Compose
- Clean Architecture + MVVM
- Retrofit для сетевых запросов
- Dependency Injection (Koin/Hilt)
- Модульная архитектура
